# CodeCoach HTML

Browser-based coding practice platform with Monaco editor. Zero-install, runs in any modern browser.

## Features
- Monaco code editor (JavaScript) via CDN
- 3 problems with difficulty ratings (Easy, Medium, Hard)
- Built-in test runner with pass/fail feedback
- Problem descriptions and starter code

## Problems
| Problem | Difficulty | Tests |
|---|---|---|
| Hello World | Easy | Console output check |
| Count Vowels | Medium | 3 function tests |
| Fibonacci Sequence | Hard | 3 function tests |

## Run
- `START_GUI.bat` or open `index.html`
